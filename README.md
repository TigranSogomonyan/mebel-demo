# ФОРМА — сайт магазина мебели

Одностраничный сайт-каталог для магазина мебели: примеры работ **без цен**, попапы,
формы заявок, мессенджеры. Собран по образцу структуры famlinedent.ru (одностраничник
с якорной навигацией, боковым меню и попапами вида `#popup:имя`), но с нуля — без Tilda,
на чистых HTML/CSS/JS. Никакой сборки и зависимостей: открыл `index.html` — работает.

**Визуальный приём** — страница печатного каталога мастерской: бумажный фон, чернильный
текст, киноварь только на акцентах; прямые углы вместо скруглений, линии-разделители
вместо теней и карточек, моноширинный шрифт для служебных подписей (артикулы, размеры,
лейблы полей). Изображения каталога — эскизы в ортогональной проекции с размерными
выносками и основной надписью, фон эскиза совпадает с фоном страницы.

## Запуск

```bash
# просто открыть
open index.html

# или локальный сервер (нужен, если будете подключать отправку форм)
python3 -m http.server 8000   # → http://localhost:8000
```

## Структура

```
index.html            вся разметка страницы и попапов
css/styles.css        стили (все цвета и шрифты — в :root сверху файла)
js/catalog-data.js    ← ДАННЫЕ: категории и товары. Правится чаще всего
js/app.js             логика: попапы, фильтр, галерея, слайдер, формы
img/catalog/          картинки каталога (SVG-заглушки)
img/ui/favicon.svg    иконка вкладки
tools/gen-images.mjs  генератор заглушек (node tools/gen-images.mjs)
```

## Что умеет

- **Каталог без цен.** 17 примеров работ в 8 категориях. Вместо цены — «Цена по проекту».
- **Направления** — оглавление со сменой эскиза-превью при наведении, а не сетка плиток.
- **Фильтр по категориям** + кнопка «Показать ещё» (по 5 работ; в сетке две первые
  работы каждой пятёрки шире остальных — ряд не читается как одинаковые карточки).
- **Попап товара**: галерея из 3 фото с миниатюрами, описание, таблица характеристик
  (материалы, фурнитура, габариты, срок), кнопка «Рассчитать под мои размеры».
- **Лайтбокс** — фото на весь экран, листается стрелками и клавишами ←/→.
- **Попапы по адресу**, как на референсе: `site.ru/#popup:order`, `#popup:infoblock`,
  `#popup:product-kuhnya-nord`. Такую ссылку можно ставить в шапку профиля соцсети —
  страница откроется сразу с нужным окном. Работают кнопка «назад», Esc и клик по фону.
- **Формы**: заявка на замер, отправка плана квартиры, заявка с главной. Валидация,
  маска телефона, попап «Спасибо».
- **Мобильная версия**: бургер-меню, панель Telegram / WhatsApp / звонок внизу экрана.
- Слайдер отзывов со свайпом, подсветка активного пункта меню при прокрутке.
- Артикулы (`КХ-01`, `ШК-02`, …) считаются автоматически из категории и порядка товара.

## Как править под себя

### 1. Товары и категории — `js/catalog-data.js`

Один товар — один объект. Скопируйте существующий и поменяйте поля:

```js
{
  id: 'kuhnya-nord',            // латиницей, без пробелов. Это же адрес попапа:
                                // #popup:product-kuhnya-nord
  cat: 'kitchen',               // id категории из CATEGORIES выше
  title: 'Кухня «Норд»',
  tagline: 'Короткая подпись под названием',
  badges: ['Без ручек', 'Матовый МДФ'],       // метки на карточке
  text: 'Абзац описания в попапе.',
  specs: [['Корпус', 'ЛДСП 18 мм'], ...],     // строки таблицы характеристик
  images: ['img/catalog/kuhnya-nord-1.jpg', ...],  // 1–5 фото, первое — обложка
}
```

Счётчики в фильтрах и на плитках категорий считаются автоматически.

### 2. Фотографии

Сейчас в `img/catalog/` лежат сгенерированные эскизы (`node tools/gen-images.mjs`).
Положите свои снимки туда же (JPG/WebP, ~1600×1200, до 300 КБ) и укажите пути в `images`.
Ширина изображения тянется по колонке, высота свободная — жёсткой пропорции нет,
так что фото и эскизы можно смешивать.

Если хотите оставить эскизы и добавить новую позицию — допишите её в массив `ITEMS`
в конце `tools/gen-images.mjs` (слug, имя сцены, номер тона, артикул) и перезапустите
генератор. Сцены (`kitchen`, `wardrobe-open`, `sofa`, …) описаны там же выше.

### 3. Контакты, тексты, ссылки — `index.html`

Найдите и замените по всему файлу:

| Что | Значение-заглушка |
|---|---|
| Название | `ФОРМА` |
| Телефон | `+7 (000) 000-00-00` и `tel:+70000000000` |
| Почта | `hello@forma-mebel.ru` |
| Telegram | `https://t.me/` |
| WhatsApp | `https://wa.me/70000000000` |
| Адрес | `г. Москва, ул. Примерная, 12, стр. 3` |
| Цифры в hero | `14 лет`, `2 400+`, `5 лет` |

Отзывы — блок `<section id="reviews">`, каждый отзыв это `<article class="review">`.
Текст политики обработки данных в попапе `#popup-privacy` — шаблонный, замените
на свою редакцию.

### 4. Карта

В блоке `#map` вместо `<div class="map__stub">` вставьте iframe Яндекс.Карт или 2ГИС —
стили под него уже есть (`.contacts__map iframe`).

### 5. Отправка заявок

Сейчас заявка пишется в консоль браузера. В `js/app.js` найдите комментарий
`ЗДЕСЬ ПОДКЛЮЧАЕТСЯ ОТПРАВКА` и раскомментируйте `fetch` на свой обработчик,
Telegram-бота или CRM. В объекте `data` уже собраны имя, телефон, категория,
комментарий, тема заявки (`topic` — из какой кнопки пришла) и адрес страницы.

### 6. Цвета и шрифты

Всё в начале `css/styles.css`, блок `:root`:

| Переменная | Роль |
|---|---|
| `--paper`, `--paper-2` | фон страницы и фон подложенных секций |
| `--ink` + `--ink-70/50/35` | текст и его приглушённые варианты |
| `--rule`, `--rule-soft` | линии-разделители (они здесь вместо теней и рамок карточек) |
| `--red` | киноварь: активный фильтр, номера, ссылки при наведении, ошибки формы |
| `--sans`, `--mono` | Golos Text и JetBrains Mono |

Если меняете `--paper`, поменяйте и константу `PAPER` в `tools/gen-images.mjs`,
затем перегенерируйте эскизы — иначе листы перестанут совпадать с фоном страницы.

Шрифты подключены с Google Fonts в `<head>`. Оба поддерживают кириллицу; при замене
следите, чтобы у гарнитуры был кириллический набор, и оставляйте запасные в стеке.

## Публикация

Статика — подойдёт любой хостинг: Netlify, Vercel, GitHub Pages, Timeweb, обычный
FTP. Залейте папку целиком. Перед публикацией замените `og:`-теги и `<title>`.

## Проверено

Сайт прогнан автотестами в реальном Chrome (32 проверки): мобильная вёрстка на 390px
без горизонтального скролла, бургер-меню и блокировка прокрутки, фильтры, догрузка
работ, попап товара и адрес `#popup:product-…`, галерея и лайтбокс, Esc и очистка
адресной строки, валидация и маска телефона, отсутствие цен в тексте страницы,
чистая консоль.
