# Кейс: FAM — сайт-каталог мебели на заказ

## 1. Проект
**FAM (family furniture)** — одностраничный сайт-каталог мебели на заказ: примеры работ без цен, попапы, заявки в Telegram.

## 2. Для кого и задача
- Клиент: мебельный салон/мастерская в Москве (салон на Покровской, производство в России и Армении). Аудитория — частные заказчики кухонь, шкафов, спален и т.п.
- Задача: показать работы, объяснить процесс и довести посетителя до заявки на замер.
- Кто заказчик юридически, был ли договор/бриф — **спросить Тиграна**.

## 3. Что сделал сам
Из кода и истории видно: вёрстка, JS, генератор эскизов, сборщик, посредник для заявок, тексты разделов, контакты.
- Дизайн (концепция «страница печатного каталога»), логотип, тексты — авторство **спросить Тиграна** (в репозитории только favicon-логотип «FAM» и тексты в коммитах).
- Участие ИИ-ассистента в коде — **спросить Тиграна**, как указывать в портфолио.

## 4. Стек и ключевые решения
- Чистые HTML/CSS/JS, без фреймворков и зависимостей; Golos Text + JetBrains Mono (woff2, локально).
- Данные каталога — один файл `js/catalog-data.js` (17 работ, 8 категорий), артикулы считаются автоматически.
- Эскизы мебели — SVG, генерируются скриптом `tools/gen-images.mjs`.
- `tools/build-single.mjs` собирает весь сайт в один `docs/index.html` (стили, JS, шрифты, картинки как data:URI) и добавляет CSP с sha256-отпечатками скриптов.
- Заявки: сайт → Google Apps Script (посредник, токен бота там) → Telegram-канал.
- Хостинг: GitHub Pages.

## 5. Фишки
1. Визуальный язык печатного каталога: бумажный фон, линии вместо теней, прямые углы, киноварь только на акцентах; эскизы в ортогональной проекции с размерными выносками и основной надписью.
2. Попапы с адресами `#popup:product-kuhnya-nord` — ссылку можно поставить в шапку соцсети, откроется сразу окно товара.
3. Нулевые сторонние запросы при открытии + строгая CSP; карта грузится только после нажатия.
4. Токен Telegram-бота не на сайте; посредник сам валидирует поля, файл до 10 МБ, антиспам (ловушка, лимиты).
5. Мобильная версия с нижней панелью Telegram / WhatsApp / звонок; сайт работает и без сборки — просто открыть `index.html`.
