# Посредник для заявок: сайт → Google Apps Script → Telegram

Токен бота хранится в Google-аккаунте, внутри этого скрипта. На сайт попадает
только адрес скрипта — по нему можно лишь отправить заявку в ваш канал.

## 1. Бот и канал

1. Telegram → **@BotFather** → `/newbot` → имя и юзернейм (на `bot`). Сохраните токен.
2. Создайте **частный** канал для заявок.
3. Канал → Настройки → Администраторы → добавьте бота с правом «Публикация сообщений».
4. Опубликуйте в канале любое сообщение, например «тест».

## 2. Скрипт

1. Откройте https://script.google.com → **Новый проект**. Назовите, например, «FAM заявки».
2. Удалите всё в `Код.gs` и вставьте содержимое файла `Code.gs` из этой папки. Сохраните (Ctrl/Cmd+S).
3. Слева **Настройки проекта** (шестерёнка) → внизу **Свойства скрипта** → Добавить свойство:
   - `TELEGRAM_TOKEN` = токен от BotFather
4. Вернитесь в **Редактор**, в выпадающем списке функций выберите `findChatId` → **Выполнить**.
   Google попросит разрешения: «Проверить разрешения» → аккаунт → «Дополнительно» →
   «Перейти на страницу проекта (небезопасно)» → «Разрешить». Это ваш собственный скрипт.
5. В «Журнале выполнения» появится строка `TELEGRAM_CHAT_ID = -100…`. Добавьте это
   свойство в «Свойства скрипта» так же, как токен.
6. Выберите функцию `testSend` → **Выполнить**. В канал должна прийти тестовая заявка.

## 3. Публикация

1. **Начать развёртывание** → **Новое развёртывание** → шестерёнка «Выберите тип» → **Веб-приложение**.
2. Запуск от имени: **Я**. У кого есть доступ: **Все**.
3. **Начать развёртывание** → скопируйте адрес вида `https://script.google.com/macros/s/…/exec`.
4. Этот адрес вставляется в `js/app.js` в `LEADS_ENDPOINT` (или пришлите его разработчику).

## Если что-то поменялось

- **Сменили токен или канал** — поменяйте свойство скрипта, переразвёртывать не нужно.
- **Поменяли код скрипта** — «Начать развёртывание» → «Управление развёртываниями» →
  карандаш → Версия: **Новая версия** → «Развернуть». Адрес останется прежним.
- **Проверить, что скрипт жив** — откройте его адрес в браузере, должно быть `{"ok":true,…}`.
